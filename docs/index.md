# Documentation map

Temporary folder, removed with `.claude/` and `archive/` when the research is final. Start with the row that matches your question.

| Question | Page | State |
|---|---|---|
| What are the results? | [`results.md`](results.md) | current; tables wait for new runs |
| Which runs are done, and what comes next? | [`progress.md`](progress.md) | current |
| How are questions asked, answers read and scores computed? | [`method.md`](method.md) | approved method |
| How is the code organised, and which commands do I run? | [`code_guide.md`](code_guide.md) | current |
| What was checked in the repository, and what is still open? | [`audit.md`](audit.md) | audit of 2026-11-19, with the open decisions |
| Why was Version 2 designed this way? | [`v2_proposal.md`](v2_proposal.md) | the original plan, partly superseded (its first page says which parts) |

Other places:

- `data/<dataset>/datasheet.md` and `dataset_report.md`: what each dataset holds and how it was built.
- `results/<dataset>/closed_book/<model>/<run>/report.md`: the full report of one run.
- `archive/v1/`: Version 1, obsolete, kept for reference.
